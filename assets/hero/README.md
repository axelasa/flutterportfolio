# Original hero app concepts

Created with the built-in image-generation tool for the animated phone showcase. These are fictional interface concepts, labelled as such on the website, separate from client project screenshots.

- `concept-planner.jpg`: warm ivory daily planner with an architectural photograph and a short task list.
- `concept-focus.jpg`: matching charcoal focus timer with a restrained orange progress ring.

Both images were generated as flat, edge-to-edge portrait screen content without device hardware. CSS supplies the phone frames and existing motion. JPEG exports preserve the full screen proportions and reduce download size.

## Prompt briefs

Planner: Original premium daily-planning mobile screen, 9:19.5 portrait, warm ivory and charcoal with restrained burnt orange, DM Sans-like typography. Title “Your day, considered.” Architectural photograph, “Make room for what matters.” caption, three tasks and bottom navigation. No device frame, perspective, logos, gradients, or existing brands.

Focus: Companion portrait focus-timer screen, warm charcoal and ivory with restrained orange. Title “One thing at a time.” Circular progress ring showing “24:59” and “DEEP WORK”, pause button, session summary, and bottom navigation. No device frame, perspective, logos, neon, gradients, or existing brands.
